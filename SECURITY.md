# Security policy

## Supported versions

Security fixes are applied to the latest published version.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** flow under the repository Security tab. Do not post credentials, private target URLs, session data, captured pages, or exploit details in a public issue.

Include the affected version, a minimal reproduction against a system you own or are authorized to test, the expected behavior, and the observed impact. Remove secrets and personal data from screenshots and logs.

## Scope and responsible use

SB Stealth Wrapper is intended for authorized QA and browser-resilience testing. Reports that depend on unauthorized access to third-party systems are out of scope.
